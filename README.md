# RetroCommitWizard

Этот проект предназначен для генерации активности на GitHub задним числом.  
Скрипт позволяет автоматически создавать коммиты с произвольными датами в прошлом,  
что отражается на графике активности профиля.

## Возможности

- Коммиты с прошлыми датами
- Случайные сообщения коммитов
- Гибкий диапазон дат
- Простая настройка и запуск

## Как использовать

1. Настрой Git, клонируй репозиторий
2. Подключи GitHub-токен
3. Запусти генератор коммитов
